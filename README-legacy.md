# Telegram-бот для OLX.uz

Бот следит за выбранными поисками на OLX.uz и присылает новые объявления в Telegram. При первой проверке он запоминает текущую выдачу, поэтому старые объявления не заполнят чат

## Как установить

Понадобятся Git, Docker с командой `docker compose` и токен бота от [@BotFather](https://t.me/BotFather)

```sh
git clone https://github.com/codexc01/olxparser013.git
cd olxparser013
cp .env.example .env
chmod 600 .env
```

Откройте `.env` в редакторе и заполните два поля

* `BOT_TOKEN` хранит токен от BotFather
* `POSTGRES_PASSWORD` задаёт пароль новой базы. Сгенерируйте его командой `openssl rand -hex 32`

Запустите бот и базу одной командой

```sh
docker compose up -d --build
```

## Запуск на Bot-Hosting.net

1. Создайте приложение из этого GitHub репозитория, выберите среду Python 3.12 и ветку `main`
2. Укажите входной файл `run.py`
3. Добавьте секретную переменную `BOT_TOKEN` с токеном BotFather
4. Добавьте `DATABASE_URL` со значением `sqlite+aiosqlite:///./olx-monitor.db`
5. Добавьте `ADMIN_IDS` со значением `[]` или массивом Telegram ID администратора
6. Запустите развёртывание и проверьте журнал запуска

В бесплатном развёртывании база хранится в файле `olx-monitor.db` рядом с ботом. Для PostgreSQL создайте отдельную базу и замените начало выданной строки подключения `postgresql://` на `postgresql+asyncpg://`

## Как пользоваться

1. Откройте бота в Telegram и нажмите `/start`
2. Выберите «🔎 Добавить поиск». Проще всего настроить город, цену и категорию на OLX и вставить ссылку на получившуюся выдачу
3. Назовите поиск, выберите интервал в 3 или 5 минут и нажмите «Сохранить». Необязательные поля можно пропустить
4. В разделе «Мои поиски» можно изменить условия или поставить поиск на паузу. История хранится в PostgreSQL и сохраняется после перезапуска

## Что где лежит

| Путь | Назначение |
| --- | --- |
| `app/ui.py` | Меню Telegram и настройка поисков |
| `app/source.py` | Загрузка страниц OLX и фильтрация объявлений |
| `app/monitor.py` | Планировщик, поиск новых объявлений и очередь доставки |
| `app/db.py`, `migrations/` | Таблицы PostgreSQL и обновления схемы |
| `app/main.py`, `app/config.py` | Запуск бота и настройки окружения |
| `tests/` | Тесты и сохранённый образец выдачи OLX |

## Обслуживание

```sh
docker compose logs --tail 100 -f bot                    # Логи бота
docker compose stop                                      # Остановка
docker compose up -d                                     # Повторный запуск
docker compose exec -T db pg_dump -U monitor -Fc monitor > monitor.dump
docker compose run --rm bot python -m pytest -q           # Базовые тесты
```

Для диагностики укажите свой числовой Telegram ID в `ADMIN_IDS`, например `[123456789]`, примените настройки командой `docker compose up -d` и отправьте боту `/admin`
